# Media policy

This file holds asset classes and nothing else. Set each class to `allow`, `deny` or `ask`.

- `allow`: the class may be used.
- `deny`: the class must not appear in any output.
- `ask`: pause only the action that needs that one asset and request a decision. The answer applies to that asset in that run and does not change this file.

Planning, copy, and own-media work are never blocked by this file. Code-drawn geometry is the separate class `coded-graphics` and is not generated media.
